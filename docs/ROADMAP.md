# 开发路线图

## 阶段 0：两天 MVP（已完成）

- [x] 可复现的 archiso 构建工程与一键 `build.sh`
- [x] KDE Plasma 6 的 Windows 11 风格布局与品牌主题
- [x] Wine / Bottles / Proton 集成与 `xuan-winrun` 关联
- [x] `xuan-ctl` 基础管理命令与 PySide6 欢迎中心
- [x] Calamares 图形安装与静态测试套件

## 阶段 1：稳定化（进行中）

- [x] 驱动安装向导 `xuan-drivers`：NVIDIA/AMD/Intel 与外设检测
- [x] 接入 CI：提交触发静态检查，定时产出 nightly ISO
- [x] Flatpak/Flathub 集成与初始化脚本
- [x] Calamares 全套模块配置，支持 LUKS 加密与多文件系统
- [ ] 建立 `xuanos-pkg` 源码包流水线，原创工具独立打包入库
- [ ] 多盘、LVM 与加密分区的实机安装测试矩阵
- [ ] 发布首个带签名的正式版本与升级说明

## 阶段 2：体验深化（3-6 个月）

- 图形化软件中心：仓库浏览、Flatpak 与 Bottle 统一入口
- 系统更新面板：内核版本管理、回滚与更新通知
- 电源与性能模式集成，笔记本续航调优
- 高 DPI、多显示器与无障碍能力专项改进
- 更完整的 Windows 软件兼容数据库与一键修复工具

## 阶段 3：生态与扩展（6 个月以上）

- Ubuntu 版（deb 系）构建 profile，复用同一套原创工具与品牌
- 可复现构建的独立签名密钥体系与安全公告流程
- 官方文档站、多语言翻译与社区包维护机制
- 评估不可变根文件系统（image-based）变体，兼顾系统原子升级

## 设计原则

- 优先上游贡献，能进入上游的修复不长期私有维护；
- 每个默认项可被用户更改，不做锁定式体验；
- 任何新依赖必须有明确来源与开源许可证，不引入专有二进制。
