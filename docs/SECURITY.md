# 安全设计

## 默认基线

- **防火墙**：ufw 默认启用，入站拒绝、出站允许，规则在 chroot 定制阶段
  写入并随系统启动。
- **最小权限**：Live 免密 sudo 仅存在于试用环境，Calamares 安装后自动
  删除；日常账户通过 wheel 组按标准 sudo 授权。
- **内核加固**：`sysctl.d/99-xuanos.conf` 开启 dmesg 限制、内核指针
  隐藏、反向路径过滤与 SYN Cookie。
- **签名仓库**：仅配置官方签名源，pacman 强制校验软件包签名。
- **服务收敛**：默认不启用 SSH 等远程接入服务，蓝牙与打印服务按需使用。

## 更新与漏洞跟踪

- 滚动仓库快速推送上游安全补丁，`xuan-ctl update` 一条命令完成
  镜像刷新与全量升级；
- `arch-audit` 对照 Arch 安全公告列出受影响包，可纳入定期巡检；
- `fwupd` 支持对支持 LVFS 的设备更新固件。

## 账户与凭据

- 安装器创建的用户密码由 Calamares 加密写入 `/etc/shadow`，权限 0400；
- KDE Wallet 提供本地密钥存储，屏幕锁定与 SDDM 使用统一 PAM 认证链。

## 兼容层安全

Wine 不是沙箱：其中运行的程序以当前用户身份执行，不额外提权但也不被
隔离。需要隔离未知软件时，应使用 Bottles 的独立前缀，或在虚拟机中
运行。

## 供应链与可复现性

- 构建期不启用第三方二进制源，所有包来自官方仓库；
- 构建产物附 SHA256 校验和，支持 `SOURCE_DATE_EPOCH` 固定时间戳；
- 原创代码与配置全部在本仓库可见，测试套件对脚本和配置做静态校验，
  便于审计与二次构建。

## 建议的用户实践

1. 安装后及时运行 `xuan-ctl update` 并定期更新；
2. 不长期保留 Live 免密配置，安装完成后用 `xuan-ctl doctor` 确认已移除；
3. 仅从可信来源获取软件与 Windows 可执行文件；
4. 笔记本等移动设备启用全盘加密（Calamares 分区阶段支持 LUKS）。
